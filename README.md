# Hydrodynamic characterization of the coastal pioneer array ocean observing system
> Jeff Grasberger, Dominic Forbush, Johannes Spinneken, Mark Bruggemann, Jantzen Lee, Alex Franks, John Reine, Giorgio Bacelli, Albert Plueddemann, Donald Peters, and Ryan G. Coe 
>
> Journal of Ocean Engineering and Marine Energy, April 2025
>
> [DOI 10.1007/s40722-025-00392-y](https://doi.org/10.1007/s40722-025-00392-y)

This repository contains the numerical model and data used for the above publication. The 
- batchRunResults: setup, data, and analysis from tuning runs of WEC-Sim model including:
- WEC-Sim Model: WEC-Sim model setup (hydrodynamic data, Simulink model, input file) and basic analysis results including:
  - full-directional spectrum waves
  - observed data for comparison
  - multiple condition run setup and results for the 4 wave cases and response amplitude operators (RAOs)
  - post-processing scripts for the 4 wave cases and response amplitude operators (RAOs)
  - mooring setup
  - phase analysis

Version:
This model was created in MATLAB R2023b and is compatible with WEC-Sim v6.1.2.
